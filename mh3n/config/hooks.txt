# Hook points: recompiled game functions that the port's native code can wrap or replace
# (see RHookFn in tools/recomp/runtime/recomp.h). MH3U USA v1.0 addresses.
# Format: <address> <name>  # purpose. Adding or removing one changes the generated code and the code library's id
# (tools/build_game.py ID_FILES; docs/MH3U.md "The code library id"), so every player builds the library again.
#
# port/src/hooks.cpp installs an MH3U library's hook points from its own table for this game (MH3U_HOOKS, by name), not
# MH4U's. A name here reuses an MH4U hook's name only when port/src's handler for it has been checked against this
# game's function (same object layout).
0x005920b0 sMain::updateFrameTiming   # frame-rate cap and pacing: the same code as MH4U's 0x006442f8 (cap f32 at +0x30, rate +0x2c, delta +0x5c); the game's own cap is off (3000), the port caps it at the console's 30 or the app's limit
0x00838a94 uEnemy::addPartDamage      # the damage numbers' "By hit" (hunt_aids.cpp): the hit step 0x00983ce4 hands each hit's total to it (its only caller, at 0x00984b68) with the hit in r4 (+0x0e how well it landed, +0x48 fixed, +0x50 the elements) and its raw and element parts in s16 / s17
# ---- mh3u-qol (port/src/mh3u_qol.cpp: MH3U's gameplay features) ----
0x00267104 uGameCamera::turnByInput   # the hunter's camera turned by its actions (6/8 the yaw, L, the Target Cam): data+0x94 yaw, +0x90 pitch; the mouse's turn and the lock-on after it
0x008afc28 uPlayer::updateInput   # the hunter's input step each frame (its vtable's; [hunter+0xd5c]+0x194 the pad words and the action bits it builds): hold A to gather, the flex's and the sharpening's cancel
